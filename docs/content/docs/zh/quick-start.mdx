只需几分钟即可开始使用 Orval。

## 不使用配置文件

使用 Orval 最简单的方式是直接通过命令行：

```bash
orval --input ./petstore.yaml --output ./src/petstore.ts
```

- `--input` 接收任意 YAML 或 JSON 格式的 OpenAPI 规范
- `--output` 指定生成文件的目标路径

## 使用配置文件

如果需要更精细的控制，可以创建配置文件。Orval 会自动在项目根目录查找 `orval.config.js`、`orval.config.ts` 或 `orval.config.mjs`。

```bash
orval --config ./orval.config.js
# 或直接执行
orval
```

### 配置示例

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    input: './petstore.yaml',
    output: './src/petstore.ts',
  },
});
```

## 生成 React Query Hooks（钩子）

想要改为生成 React Query Hooks（钩子）？只需要设置 `client` 选项：

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    input: './petstore.yaml',
    output: {
      target: './src/api/petstore.ts',
      schemas: './src/api/model',
      client: 'react-query',
    },
  },
});
```
