---
title: Custom HTTP Client（自定义 HTTP 客户端）
description: 使用 mutator 配置自定义 HTTP 客户端
---

使用 mutator 配置选项创建自定义 HTTP 客户端。

## 配置

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    output: {
      // ...
      override: {
        mutator: {
          path: './api/mutator/custom-instance.ts',
          name: 'customInstance',
        },
      },
    },
  },
});
```

## 自定义实例实现

```ts title="custom-instance.ts"
const baseURL = '<BACKEND URL>'; // 使用你自己的 URL 或环境变量

export const customInstance = async <T>(
  url: string,
  {
    method,
    params,
    body,
  }: {
    method: 'GET' | 'POST' | 'PUT' | 'DELETE' | 'PATCH';
    params?: any;
    body?: BodyType<unknown>;
    responseType?: string;
  },
): Promise<T> => {
  let targetUrl = `${baseURL}${url}`;

  if (params) {
    targetUrl += '?' + new URLSearchParams(params);
  }

  const response = await fetch(targetUrl, {
    method,
    body,
  });

  return response.json();
};

export default customInstance;

// 为 react-query 和 swr 覆盖返回错误类型
export type ErrorType<Error> = AxiosError<Error>;

// 如有需要，对 body 类型进行包装（例如用于大小写转换）
export type BodyType<BodyData> = CamelCase<BodyData>;
```

## 重新导出 mutator

`mutator.path` 引用的文件也可以从其他模块重新导出命名的 mutator：

```ts title="custom-instance.ts"
export { customInstance } from '@acme/api-client/mutators';
```

命名重导出会被视为有效的 mutator 导出。由于被重导出的实现位于配置文件之外，Orval 会使用标准的单请求参数 mutator 形态来检测参数。如果生成的客户端需要额外的请求选项参数，请使用带显式参数的本地包装函数。

## Angular HTTP Client（Angular HTTP 客户端）

对于 Angular，请为 HttpClient 配置一个 mutator：

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    output: {
      // ...
      override: {
        mutator: 'src/api/mutator/response-type.ts',
      },
    },
  },
});
```

```ts title="response-type.ts"
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';

const responseType = <Result>(
  {
    url,
    method,
    params,
    data,
  }: {
    url: string;
    method: string;
    params?: any;
    data?: any;
    headers?: any;
  },
  http: HttpClient,
): Observable<Result> =>
  http.request<Result>(method, url, {
    params,
    body: data,
    responseType: 'json',
  });

export default responseType;
```
