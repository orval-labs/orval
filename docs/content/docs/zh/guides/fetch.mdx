Fetch API 是浏览器原生 API，不需要任何额外依赖。它同样适用于服务端框架，以及 Cloudflare Workers、Vercel Edge 和 Deno 等 edge runtime（边缘运行时）。

## 配置

将 `client` 选项设置为 `fetch`：

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    output: {
      mode: 'tags-split',
      target: 'app/gen/petstore.ts',
      schemas: 'app/gen/models',
      client: 'fetch',
      baseUrl: 'http://localhost:3000',
      mock: true,
    },
    input: {
      target: './petstore.yaml',
    },
  },
});
```

## 运行时 base URL

如果 host（主机）只会在运行时才知道（例如 Node 中的 `process.env.API_BASE_URL`，或 Vite 中的 `import.meta.env.VITE_*`），请使用 `baseUrl.runtime`，而不是固定字符串。内置 Fetch 客户端会把这个表达式嵌入生成后的 URL 模板字面量中，因此你仍然可以继续使用 `override.fetch` 选项，比如 `runtimeValidation` 和 `includeHttpResponseReturnType`，而不需要自定义 mutator。

```ts title="orval.config.ts"
baseUrl: {
  runtime: 'process.env.API_BASE_URL',
},
```

关于 `imports` 以及来自共享模块的表达式（例如 `import { env } from '../../env'` 中的 `env.API_BASE_URL`），请参见 [output `baseUrl` reference（output `baseUrl` 参考）](/docs/reference/configuration/output#runtime)。MSW Mock 的 host（主机）过滤则使用单独的 [`mock.baseUrl`](/docs/reference/configuration/output#mock-options) 选项。

## 生成结果

Orval 会为每个 endpoint 生成三部分内容：

### 1. 响应类型

```ts
export type listPetsResponse = {
  data: Pets;
  status: number;
};
```

### 2. URL 生成器

```ts
export const getListPetsUrl = (params?: ListPetsParams) => {
  const normalizedParams = new URLSearchParams();

  Object.entries(params || {}).forEach(([key, value]) => {
    if (value === null) {
      normalizedParams.append(key, 'null');
    } else if (value !== undefined) {
      normalizedParams.append(key, value.toString());
    }
  });

  return `http://localhost:3000/pets?${normalizedParams.toString()}`;
};
```

### 3. Fetch 函数

```ts
export const listPets = async (
  params?: ListPetsParams,
  options?: RequestInit,
): Promise<listPetsResponse> => {
  const res = await fetch(getListPetsUrl(params), {
    ...options,
    method: 'GET',
  });
  const data = await res.json();

  return { status: res.status, data };
};
```

## 自定义 Fetch 函数

通过 mutator 添加自定义 fetch 实现：

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    output: {
      // ...
      override: {
        mutator: {
          path: './custom-fetch.ts',
          name: 'customFetch',
        },
      },
    },
    // ...
  },
});
```

生成后的函数会使用你的自定义实现：

```ts
export const listPets = async (
  params?: ListPetsParams,
  options?: RequestInit,
): Promise<listPetsResponse> => {
  return customFetch<Promise<listPetsResponse>>(getListPetsUrl(params), {
    ...options,
    method: 'GET',
  });
};
```
