title: Valibot
description: 从 OpenAPI 生成 Valibot schema
---

从 OpenAPI 规范生成 [Valibot](https://valibot.dev/) schema，用于运行时校验。

## 配置

将 `client` 选项设置为 `valibot`：

```ts title="orval.config.ts"
import { defineConfig } from 'orval';

export default defineConfig({
  petstore: {
    output: {
      client: 'valibot',
      mode: 'single',
      target: './src/api/schemas.ts',
    },
    input: {
      target: './petstore.yaml',
    },
  },
});
```

## 生成结果

Orval 会为每个 operation 的 params、query、headers、body 和 response 各生成一个 Valibot schema。body 和 response 的 schema 来自 JSON、`multipart/form-data` 或 `application/x-www-form-urlencoded` 内容，response 依次查看 `200`、`2XX`/`2xx` 和其他 2xx 响应（`204` 和 `205` 除外），取第一个带有上述内容的响应。其他媒体类型（例如 `text/plain`）不会生成 schema：

```ts
import * as v from 'valibot';

export const CreatePetsBody = v.object({
  id: v.pipe(v.number(), v.integer()),
  name: v.string(),
  tag: v.optional(v.string()),
});
```

## 选项

选项位于 [`override.valibot`](/docs/reference/configuration/output#overridevalibot)：

- `strict` - 按位置（`param`、`query`、`header`、`body`、`response`）生成 `v.strictObject` 而不是 `v.object`。默认全部为 `false`。
- `generate` - 按位置选择是否生成 schema。默认全部为 `true`。
- `exactOptional` - 可选属性使用 `v.exactOptional`，适用于启用了 `exactOptionalPropertyTypes` 的项目。默认 `false`。也可以按 operation 或按 tag 设置。
- `generateReusableSchemas` - 每个组件 schema 只生成一次并通过引用复用，而不是内联每个 `$ref`。默认 `false`。参见[可复用 Schema](#可复用-schema)。

## 可复用 Schema

默认情况下每个 `$ref` 都会被内联，共享组件很多的规范会让输出变得很大。设置 `generateReusableSchemas` 后，每个 `#/components/schemas/*` 条目都会生成一个导出的常量：

```ts title="orval.config.ts"
export default defineConfig({
  petstore: {
    output: {
      client: 'valibot',
      target: './src/api/schemas.ts',
      override: { valibot: { generateReusableSchemas: true } },
    },
    input: { target: './petstore.yaml' },
  },
});
```

```ts
export const Pet = v.object({
  name: v.string(),
  friends: v.optional(v.array(v.lazy((): v.GenericSchema => Pet))),
});

export const ListPetsResponse = v.array(Pet);
```

常量写在 operation 旁边：`single` 模式写入 target，其他模式写入 `*.schemas.ts` 文件。闭合循环的引用通过 `v.lazy` 读取，该字段的类型为 `unknown`。

### 限制

- 目前不能与 `output.schemas` 同时使用：生成时会报错。
- 当常量的校验结果可能不同时，`$ref` 仍会被内联，例如表单请求体、`readOnly` 和 `writeOnly` 属性，以及部分 `allOf`、`oneOf` 和 `anyOf` 成员。
- 常量保留所有属性，只有在所有位置都是 `strict` 时才是 `strict`。`strict` 不同的位置，或按 operation 覆盖 `exactOptional` 时，其 schema 会被内联。
- 带 `discriminator` 的 `oneOf` 或 `anyOf`，当选项是引用时生成 `v.union`。
- 名为 `Date` 或 `RegExp` 的组件会加上 `Schema` 后缀。两个同名组件会让生成报错并停止。

## 用法

### 解析数据

```ts
import * as v from 'valibot';
import { CreatePetsBody } from './src/api/schemas';

const pet = v.parse(CreatePetsBody, { id: 1, name: 'Buddy', tag: 'dog' });
// => { id: 1, name: "Buddy", tag: "dog" }
```

### 类型推断

```ts
import * as v from 'valibot';
import { CreatePetsBody } from './src/api/schemas';

type Pet = v.InferOutput<typeof CreatePetsBody>;

const pet: Pet = { id: 1, name: 'Buddy', tag: 'dog' };
```

### 安全解析

```ts
import * as v from 'valibot';
import { CreatePetsBody } from './src/api/schemas';

const result = v.safeParse(CreatePetsBody, unknownData);

if (result.success) {
  console.log(result.output);
} else {
  console.error(result.issues);
}
```

## 映射规则

- `oneOf` 和 `anyOf` 生成 `v.union`；设置了 `discriminator` 时生成 `v.variant`。`allOf` 生成 `v.intersect`。
- 对象会去掉未知的键。`strict` 选项生成 `v.strictObject`，`additionalProperties` 生成 `v.looseObject` 或 `v.record`。
- `date` 和 `date-time` 字符串按 ISO 日期校验。设置 `override.useDates` 后会转换为 `Date`。
- 二进制字段（`format: binary`）生成 `v.file()`，包括 `multipart/form-data` 请求体中的文件字段。
- 请求体中会去掉 `readOnly` 属性，响应中会去掉 `writeOnly` 属性。
- 与 schema 不符的 `default` 会被去掉，并给出警告。

## 限制

- 循环 `$ref` 在被内联的位置按 `unknown` 校验，并给出警告。设置 `generateReusableSchemas` 后，组件常量通过 `v.lazy` 递归校验。
- `prefixItems` 元组按 `unknown[]` 校验，并给出警告。
- 除非设置 [`generateReusableSchemas`](#可复用-schema)，否则每个 `$ref` 都会被内联，共享的 schema 可能让输出变得很大。内联单个 schema 超过 250,000 个 schema 节点时会报错并停止。
- `oneOf` 不检查是否恰好只有一个备选项匹配。
- 在 `allOf` 交叉类型中，`strict` 对象会生成为 `v.object`，多余的键会被去掉而不是报错。与对象成员并列的开放成员（`additionalProperties: true`）会被省略，多余的键同样会被去掉。
- Valibot schema 暂未接入 HTTP client：目前不支持 `schemas: { type: 'valibot' }`，也不支持对响应做运行时校验。

## 与 HTTP Client 结合使用

`valibot` client 只生成 schema。若要与其他 client 配合，请在单独的输出中生成该 client，然后自行解析响应：

```ts
import * as v from 'valibot';
import { showPetById } from './src/api/endpoints';
import { ShowPetByIdResponse } from './src/api/schemas';

const response = await showPetById('1');
const pet = v.parse(ShowPetByIdResponse, response.data);
```
