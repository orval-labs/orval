Orval 可以从任意有效的 OpenAPI v3 或 Swagger v2 规范生成**类型安全的 TypeScript 客户端**，支持 YAML 和 JSON 格式。

## 为什么选择 Orval？

开发者通常把 OpenAPI/Swagger 当作前后端之间的契约。在 Orval 出现之前，[Swagger Editor](https://editor.swagger.io) 或 [Swagger Codegen](https://swagger.io/tools/swagger-codegen) 这类工具也能完成这项工作。但这已经不足以满足现代开发的需求。这就是 Orval 出现的原因。

### 主要目标

- **生成 TypeScript 模型** - 为 API 请求和响应提供完整的类型安全
- **生成 HTTP 请求函数** - 生成可直接使用且具有正确类型的请求函数
- **生成 [MSW](https://mswjs.io/) Mock** - 无需后端即可测试前端

## 支持的客户端

默认生成的客户端使用 [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)。你也可以根据项目需求配置其他客户端，例如 axios。
