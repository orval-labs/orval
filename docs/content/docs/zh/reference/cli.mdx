从 OpenAPI 规范生成类型安全的客户端。

## 基础用法

```bash
orval
```

默认情况下，Orval 会查找 `orval.config.js` 文件。

## 选项

### --input, -i

你的 OpenAPI 规范的路径或 URL：

```bash
orval --input ./petstore.yaml
```

### --output, -o

生成文件的输出路径：

```bash
orval --output ./api/endpoints/petstoreFromFileSpec.ts
```

### --config, -c

Orval 配置文件的路径：

```bash
orval --config ./api/orval.config.js
```

### --project, -p

聚焦于配置中的特定 project：

```bash
orval --project petstore
orval --project dogstore catstore
```

### --watch, -w

监听文件并在变更时重新生成：

```bash
orval --watch
orval --watch ./src
```

### --clean

在重新生成之前清理输出目录：

```bash
orval --clean
orval --clean ./src
```

<Callout type="warn">
这会清理所有输出 target 和 schemas 文件夹。
</Callout>

### --formatter

使用指定的 formatter（`prettier`、`biome` 或 `oxfmt`）格式化生成文件：

```bash
orval --formatter prettier
orval --formatter biome
orval --formatter oxfmt
```

### --tsconfig

指定 tsconfig 的路径：

```bash
orval --tsconfig ./src/tsconfig.json
```

### --log-level

设置日志级别。可选值为 `error`、`warn`、`info`、`verbose` 或 `debug`。默认值为 `info`。与 `--verbose` 和 `--quiet` 互斥：

```bash
orval --log-level warn
```

### --verbose

`--log-level verbose` 的快捷方式。与 `--log-level` 和 `--quiet` 互斥：

```bash
orval --verbose
```

### --quiet

`--log-level warn` 的快捷方式。会输出 error 和 warning；info、verbose 和 debug 会被抑制。与 `--log-level` 和 `--verbose` 互斥：

```bash
orval --quiet
```

### --fail-on-warnings

当生成过程中发出 warning 时，以错误码 1 退出。适合在 CI 流水线中强制要求无 warning 构建：

```bash
orval --fail-on-warnings
```

### --outdated

将 Orval 将要生成的内容与磁盘上已有的文件进行比较，不写入任何内容。每个需要重新生成的文件都会连同其状态一起列出，发现任何此类文件时以错误码 1 退出，便于在 CI 中捕获修改了规范或配置却忘记重新生成的情况：

```bash
orval --outdated
```

```
outdated: src/api/pets.ts
missing: src/api/model/petSummary.ts
obsolete: src/api/legacyUsers.ts
```

- `outdated`：文件存在，但内容与生成结果不一致（包括 `prettier` 的格式化结果）。
- `missing`：应当生成的文件不存在。
- `obsolete`：`clean` 会删除、且本次不再生成的文件。仅在配置了 `clean` 时报告。

即使配置了 `clean`，也不会写入或删除任何文件。运行 `orval` 即可重新生成列出的文件。

<Callout type="warn">
配置了 `hooks.afterAllFilesWrite`、`biome` 或 `oxfmt` 格式化器、或 `docs` 的项目无法检查，因为它们会在生成后修改文件。对这类项目检查会以错误结束。运行检查时请禁用这些配置。
</Callout>

与 `--watch` 互斥。
