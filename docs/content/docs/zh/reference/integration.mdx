---
title: Programmatic API（编程 API）
description: 在构建脚本中以编程方式使用 Orval
---

将 Orval 的代码生成功能集成到你的构建流程、脚本或工具中。

## 基础用法

```ts
import orval from 'orval';

// 使用配置文件路径生成
await orval('./orval.config.js');

// 使用当前目录下的 orval 配置生成
await orval();
```

或者使用具名导出：

```ts
import { generate } from 'orval';

await generate('./orval.config.js');
```

## 直接配置

直接传入配置对象：

```ts
import { generate, type Options } from 'orval';

const config: Options = {
  input: {
    target: './api-spec.yaml',
  },
  output: {
    target: './src/api.ts',
    client: 'axios',
  },
};

await generate(config);
```

## 全局选项覆盖

使用全局选项覆盖配置中的设置。全部可用选项请参考 [GlobalOptions interface](https://github.com/orval-labs/orval/blob/master/packages/core/src/types.ts#L718)。

```ts
import { generate, type GlobalOptions } from 'orval';

const globalOptions: GlobalOptions = {
  // 文件监听
  watch: true, // 启用 watch 模式（boolean）
  // watch: './specs/**/*.yaml',        // 监听特定文件模式（string）
  // watch: ['./specs/*.yaml'],         // 监听多个模式（string[]）

  // 输出控制
  clean: true, // 清理所有输出目录（boolean）
  // clean: ['./src/api', './types'],   // 清理特定目录（string[]）
  output: './src/generated', // 覆盖输出目录

  // 代码格式化（同一时间只能使用一种 formatter）
  formatter: 'prettier', // 'prettier' | 'biome' | 'oxfmt'

  // HTTP Client（HTTP 客户端）配置
  client: 'fetch', // 覆盖 Client
  httpClient: 'fetch', // HTTP 实现：'axios' | 'fetch'

  // 生成模式
  mode: 'split', // 输出模式：'single' | 'split' | 'tags' | 'tags-split'

  // Mock 数据生成
  mock: true, // 启用 mock 数据生成
  // mock: { generators: [{ type: 'msw', delay: 1000 }] },  // 配置 mock 选项

  // TypeScript 配置
  tsconfig: './tsconfig.json', // 自定义 tsconfig 路径
  // tsconfig: { compilerOptions: {...} },  // 内联 tsconfig

  // Package 配置
  packageJson: './package.json',
  input: './api-spec.yaml',

  // 日志
  logLevel: 'error', // 仅输出错误

  // 错误处理
  throwOnError: true, // 首次生成出错时直接抛出，而不只是记录日志
};

await generate('./orval.config.js', process.cwd(), globalOptions);
```

## 自定义 Workspace（工作区）

指定自定义 Workspace（工作区）目录：

```ts
import { generate } from 'orval';

const workspace = '/path/to/your/project';
await generate('./orval.config.js', workspace);
```

## 函数签名

```ts
function generate(
  optionsExport?: string | OptionsExport,
  workspace?: string,
  options?: GlobalOptions,
): Promise<void>;
```

**参数：**
- `optionsExport`：配置文件路径或配置对象
- `workspace`：工作目录（默认为 `process.cwd()`）
- `options`：用于覆盖配置设置的全局选项

## 错误处理

默认情况下，`generate()` 会记录首次生成时的错误，并在处理完已配置的一个或多个项目后完成。如果脚本需要捕获首次生成失败并自行决定如何处理，请设置 `throwOnError`：

```ts
import { generate } from 'orval';

try {
  await generate('./orval.config.js', process.cwd(), {
    throwOnError: true,
  });
} catch {
  process.exit(1);
}
```

`generate()` 会先通过当前报告器记录错误，然后再重新抛出。`logger.error` 在 `withReporter` 之外是空操作，因此不要在这个 catch 中调用它。

当配置文件包含多个项目时，`throwOnError` 会在首次运行遇到第一个生成错误时立即停止，而不是继续执行后续项目。watch 模式中的生成错误则会在 watcher 启动后继续以日志形式输出。

## Reporter（报告器）

报告器选择属于编程调用的执行上下文，不是 `orval.config.ts` 选项。内置包会向当前异步调用链上的报告器发送结构化事件（`message`、`packageName`，以及可选的 `projectName`）。

| 入口 | 默认行为 |
| --- | --- |
| 底层 API（`generateSpec`、辅助函数、格式化） | 无操作 |
| CLI（`orval`） | 输出到控制台 |
| 公开的 `generate()` | 输出到控制台；若外层已有 `withReporter`，则保留外层报告器 |

使用 `withReporter` 为一次调用链安装报告器。外层报告器始终优先于 `generate()` 的控制台默认值，因此测试可以静默输出，而不改变生产环境的调用方。

```ts
import { generate, withReporter, noopReporter, consoleReporter } from 'orval';

// 在测试中静默 generate()
await withReporter(noopReporter, () => generate(config));

// 让底层 API 使用现有的终端输出
await withReporter(consoleReporter, () => generateSpec(workspace, options));
```

自定义报告器会收到结构化事件。当项目在作用域中时，日志会在 `message` 前加上项目名称。消息保留现有文案和 ANSI 样式；如果需要纯文本，请自行去掉颜色。

```ts
import { generate, withReporter, type OrvalReporter } from 'orval';

const reporter: OrvalReporter = {
  info: (event) => process.stdout.write(`${event.packageName}: ${event.message}\n`),
  warn: (event) => process.stderr.write(`${event.packageName}: ${event.message}\n`),
  error: (event) => process.stderr.write(`${event.packageName}: ${event.message}\n`),
  verbose: (event) => process.stderr.write(`${event.packageName}: ${event.message}\n`),
  debug: (event) => {
    if (process.env.DEBUG) {
      process.stderr.write(`${event.packageName}: ${event.message}\n`);
    }
  },
};

await withReporter(reporter, () => generate(config));
```

要在测试中断言一个或多个事件，只需覆盖关心的级别：

```ts
import { generate, noopReporter, withReporter } from 'orval';
import { vi } from 'vitest';

const warn = vi.fn();

await withReporter({ ...noopReporter, warn }, () => generate(config));

expect(warn).toHaveBeenCalledWith(
  expect.objectContaining({
    packageName: 'orval',
    message: expect.stringContaining('symbolic link'),
  }),
);
```

## Watch Mode（监听模式）

```ts
import { generate } from 'orval';

// 启用 watch 模式
await generate('./orval.config.js', process.cwd(), {
  watch: true,
});

// 监听特定文件或目录
await generate('./orval.config.js', process.cwd(), {
  watch: ['./specs/*.yaml', './src/custom-types.ts'],
});
```

## 构建脚本集成

```json title="package.json"
{
  "scripts": {
    "generate": "node scripts/generate-api.js",
    "dev": "npm run generate && next dev",
    "build": "npm run generate && next build"
  }
}
```

```js title="scripts/generate-api.js"
const { generate } = require('orval');

async function main() {
  try {
    await generate();
    console.log('API client generated successfully');
  } catch (error) {
    console.error('Failed to generate API client:', error);
    process.exit(1);
  }
}

main();
```
